## 4. Why the static-tier N_k are 82, 92, 102 or 122

Firmware `firmware/03_ranging/03_initiator/03_initiator.ino`: `SPIFFS_FLUSH_EVERY` = 10; `flushLog()` calls `logFile.flush()` when `loopCount % SPIFFS_FLUSH_EVERY == 0`, and `loopCount` is incremented once per ranging cycle. A static file ends when the operator powers the puck off, so rows written after the last flush are lost and every file holds a multiple of the flush interval.
